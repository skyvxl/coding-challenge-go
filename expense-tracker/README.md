# Expense Tracker

A small CLI application for tracking personal expenses. It was built as part
of my personal Go challenges to practice working with command-line tools and
JSON storage.

## Features

- Add, list, and delete expenses
- Show total expenses, optionally for the last N months
- JSON file storage

## Run

```bash
go run . --help
```
